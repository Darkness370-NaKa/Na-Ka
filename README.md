# NAKA-SYS // 菜香姫

A cyberpunk character archive for Nakahime, set in Tekko-Kyoku, Japan, 2149.

## Website
The site is deployed with GitHub Pages from the `main` branch using the workflow in `.github/workflows/pages.yml`.

When the first deployment succeeds, it will be available at:
https://darkness370-naka.github.io/Na-Ka/

## Sections
- Home
- Character profile
- Tekko-Kyoku world archive
- Hakuryuu-07 vehicle profile
- Classified records and visual database

## Notes
This is a static HTML/CSS/JavaScript site. No backend or database is required.
